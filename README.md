# Forge Toolchain

**Forge Toolchain** is a collection of tools for building and compiling software written in the **C programming language**.

Focused in being able to compile C code for the platform:
- x86-64, ELF format

This project is being developed by a computer engineering student to learn and improve skills in **software engineering, compiler design and C development**.

## Goals

- Develop a deeper understanding of compiler architecture.
- Improve proficiency in C and systems programming.
- Apply software engineering principles to a large-scale project.
- Develop maintainable and well-documented software.
- Explore the internals of the C language and its compilation process.
