# forge-cc

`forge-cc` is a C compiler with the following goals:

- Compile C programs for **x86_64 ELF**.
- Support different versions of the **C standard**.
- Follow the lastests Standart C documentation.
- Support **POSIX** and **Windows**.
- Support multiple file encoding types.
- Generate **Warning** and **Errors** from compilation.
- Support common compiler flags used by **GCC** and **Clang**.
